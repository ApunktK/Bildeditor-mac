# Bildeditor für macOS

Eigenständiger, nativer Bildeditor für macOS (Swift, AppKit, Metal), dessen Bedienung sich an Paint.NET 5.1.12 orientiert. Kein Bestandteil von Paint.NET; keine Verbindung zu dotPDN LLC.

**Stand:** Phase 1 (Referenzanalyse) abgeschlossen – noch kein Programmcode. Details: [Documentation/IMPLEMENTATION_STATUS.md](Documentation/IMPLEMENTATION_STATUS.md).
