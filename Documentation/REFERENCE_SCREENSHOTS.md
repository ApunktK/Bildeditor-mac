# REFERENCE_SCREENSHOTS.md

Verzeichnis der Screenshots aus der offiziellen Paint.NET-Dokumentation, die als **visuelle Referenz für den UI-Vergleich** (Projektvorgabe 29) dienen. Die Bilder werden **nicht** ins Projekt kopiert (Urheberrecht dotPDN); es wird nur auf die Original-URLs verwiesen. Basis-URL: `https://paint.net/doc/latest/`.

Anzahl: 365 Screenshots (ohne Animationen und Einzel-Icons).

Ergänzend nötig (KNOWN_ISSUES R-1): eigene Screenshots einer echten Paint.NET-5.1.12-Installation auf Windows (jeder Dialog nach „Zurücksetzen“, jedes Menü, jede Werkzeugleiste), da die Doku-Screenshots teils ältere Versionen oder geänderte Werte zeigen.
